- 競合相手との比較

閃光ショックを食い合う、ブラスターやエクシディウムがライバル。

ブラスターと併用出来なくとも、ブラスターより強力な花火と併用できるので、ブラスターとの素材被りは気にしなくて良い。また、エクシディウムとの比較は、火力を一点集中させるか分散させるかという違いしかないので、好きな方を選べば解決する。
