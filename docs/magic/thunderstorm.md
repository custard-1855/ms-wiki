### 特性

| 晴天の霹靂 |
| --- |
| 落雷が1～3回連続して生成される。<br>クールタイム-25%<br>融合魔法:[雷炸裂](thunder-burst.md)の習得に必要。 |
| 雷爆発 |
| 落雷が着弾時に爆発し、拡張する。<br>落雷が順次ランダムな位置に生成される。<br>ダメージ+80%<br>融合魔法:[蒼天の怒り](wrath-of-the-heavens.md)の習得に必要。 |
| 審判 |
| 落雷が1つに統合される。<br>落雷の爆発周辺の敵には半分のダメージを与える。<br>落雷の数1毎に、サイズ+20%<br>ダメージ5倍、クールタイム<span style="color: #F54738">2倍</span><br>融合魔法:[軌道爆撃](orbital-bombardment.md)の習得に必要。 |
