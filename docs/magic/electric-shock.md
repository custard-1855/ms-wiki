| 連続稲妻 |
| --- |
| 電気ショックが1～3回連続する(敵に当たると連鎖して発生)。<br>ダメージ量+50%<br>融合魔法:[以気御剣](flying-swords.md)、[雷炸裂](thunder-burst.md)、[電流暴走](power-surge.md)、[雷の心](heart-of-thunder-old.md)の習得に必要。 |

| 超伝導 |
| 電気ショックが周辺の敵に向かって順次生成される。<br>ダメージ3倍、サイズ2倍<br>融合魔法:[テラ電流](tera-current.md)、[マイスナー効果](meissner-effect.md)の習得に必要。 |
