### 基本情報

| lv毎のステータス |  |  |  |  |  |

| 1 | ランダムな地点に隕石を落とす。 |  |  |  |  |

### 特性

| 火山爆発 |
| --- |
| 隕石がすぐに爆発して噴火口を残し、毎秒25%分のダメージを与える。<br>(噴火口の持続時間:3秒)<br>融合魔法:[溶鉱炉](furnace.md)、[大亀裂](great-rift.md)、[炎の嵐](firestorm.md)の習得に必要。 |
| 流星群 |
| 数3倍、生成間隔(≠クールタイム)-30%<br>ダメージ<span style="color: #F54738">-25%</span>、サイズ<span style="color: #F54738">-25%</span><br>融合魔法:[蒼天の怒り](wrath-of-the-heavens.md)、[戦争気候](war-climate.md)の習得に必要。 |
| 小惑星 |
| 隕石が1つに統合される。隕石の数1つ毎にサイズ+50%<br>ダメージ3倍、クールタイム<span style="color: #F54738">2倍</span><br>融合魔法:[ヒペリオン](hyperion-old.md)、[大衝突](great-collision.md)の習得に必要。 |
