# 雷の調律

## 基本情報

### 評価

- 出力

融合魔法最弱。感電地帯の内側へのダメージが無くなり、エフェクトに直撃しないとダメージを与えられなくなる。サイズを上げると半径が上がり、より攻撃を当てにくくなり、囲まれた時に押しつぶされる。おまけに火力も低く、序盤以外で全く役に立たないだろう。

- 競合相手との比較

いない。

- 特記事項

弱いので使うと損をする。
