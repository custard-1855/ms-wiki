### 基本情報

| --- | --- | --- | --- | --- | --- |

### 特性1

| 魔力の矢 |
| --- |
| 魔力弾がすべての敵を貫通する。<br>ダメージ+80%、サイズ+180%、速度+180%<br>融合魔法:[ブラスター](blaster.md)の習得に必要。 |
| 花火 |
| 魔力弾が3発に分散し爆発する。<br>ダメージ+50%、クールタイム<span style="color: #F54738">+2秒</span><br>融合魔法:[花火](fireworks.md)の習得に必要。 |
| 分裂 |
| 魔力弾が追加で2つの物を指定して発射される。 |

### 特性2

| 連続詠唱 |
| --- |
| 数+1、クールタイム-20% |
| 乱射 |
| 魔力弾がランダムな位置に発射される。<br>数5倍、ダメージ+50%、クールタイム<span style="color: #F54738">+3秒</span><br>融合魔法:[フレンジー](frenzy.md)、[嵐の支配者](storm-ruler.md)、[プリズム乱射](prism-barrage.md)の習得に必要。 |
| ドッペルゲンガー |
| キャラクターの代わりに魔力弾を発射する幻影を3つ召喚する。<br>クールタイム<span style="color: #F54738">+50%</span><br>融合魔法:[アバター](avatar.md)の習得に必要。 |
