# ゲーム概要

### あらすじ

> 何十年にもわたる魔法使いの戦争で、あまりにも多くの死の魔法が乱用されてきました...自然に住む精霊は、そこに浸透した魔法の残党によって悪魔になり、すべての生き物をむさぼり食う。 --- Google Playの説明文より引用

### 遊び方

- Startを押してClass、Stageを選択するとゲームが始まります。
- キャラクターを操作して強化しながら、敵を倒して生き残り続けよう！（詳しい説明は参考記録へ）
