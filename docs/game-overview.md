## 遊び方

<ol class="ms-steps">
  <li class="ms-step">
    <figure class="ms-step__img"><img src="../assets/images/database/basics/elite-monsters.png" alt="敵の群れに囲まれた実験体" loading="lazy"></figure>
    <div class="ms-step__body">
      <p class="ms-step__title">敵を倒す</p>
      <p>精霊の成れの果てが四方から押し寄せる。指一本で動き回り、魔法は自動で放たれる。</p>
    </div>
  </li>
  <li class="ms-step">
    <figure class="ms-step__img ms-step__img--orbs">
      <img src="../assets/images/database/basics/mana-s.jpg" alt="マナオーブ(小)" loading="lazy">
      <img src="../assets/images/database/basics/mana-m.jpg" alt="マナオーブ(中)" loading="lazy">
      <img src="../assets/images/database/basics/mana-l.jpg" alt="マナオーブ(大)" loading="lazy">
    </figure>
    <div class="ms-step__body">
      <p class="ms-step__title">マナを集める</p>
      <p>倒した敵が落とすマナオーブを拾ってレベルアップ。宝箱やオベリスクからはアーティファクトが手に入る。</p>
    </div>
  </li>
  <li class="ms-step">
    <figure class="ms-step__img"><img src="../assets/images/database/basics/levelup.png" alt="レベルアップ時の魔法選択画面" loading="lazy"></figure>
    <div class="ms-step__body">
      <p class="ms-step__title">魔法を選ぶ</p>
      <p>レベルアップのたびに 3 つの魔法から 1 つを選ぶ。何を取るかで、その回の戦い方が決まる。</p>
    </div>
  </li>
  <li class="ms-step">
    <figure class="ms-step__img"><img src="../assets/images/overview/magic/super-typhoon.jpg" alt="融合魔法スーパー台風" loading="lazy"></figure>
    <div class="ms-step__body">
      <p class="ms-step__title">融合・究極</p>
      <p>特性を揃えた魔法どうしを<a href="../database/magic/">融合</a>させ、さらに条件を満たせば究極魔法へ。画面が魔法で埋まる。</p>
    </div>
  </li>
  <li class="ms-step">
    <figure class="ms-step__img"><img src="../assets/images/overview/clear.jpg" alt="クリア画面「実験成功」" loading="lazy"></figure>
    <div class="ms-step__body">
      <p class="ms-step__title">生き残る</p>
      <p>エリアのクリア時間まで耐えきれば<b>実験成功</b>。無限モードなら、倒れるまで記録を伸ばし続ける。</p>
    </div>
  </li>
</ol>
