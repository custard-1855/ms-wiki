# 実験体

## 実験体について

![Testsubject](../assets/images/database/test-subjects/testsubject.png){ width="189" height="297" }

実験体とは、ジェム800を消費して獲得出来る、[クラス](classes.md)と同名のスキンのようなものです。

獲得すると、どの実験体を選んでいても発動する常在効果を解放したり、各実験体に応じたAFをステージ進入時に持ち込めたりします。

以下は実験体の名称、持ち込めるAF、常在効果の一覧です。

特に強力な実験体はTier<span style="color: #0068b7">**A**</span>、<span style="color: #b33e5c">**S**</span>として色を変更しています。
