# 用語集

## 公式用語

### [クラス](classes.md)

ドラクエ等でいうところの職業のこと。

職種によって様々な恩恵がある。

### [実験体](test-subjects.md)

マインクラフトでいうところのスキンのこと。

スキン購入はジェム800個で買える。

ステージ内での自キャラの見た目を変える他、ステージ進入時、スキンごとに決められたAFを持ち込める上、スキンを購入していさえすれば、スキンを選択していなくても発動する常在効果を得られる。

### ジェム

ゲームオーバー時に獲得出来る。

[実験体](test-subjects.md)の購入、[クラス](classes.md)の凸の為のガチャを回すのに必要。

### マナ

マナオーブ[^1]を拾うことで獲得出来る、経験値のようなモノ。

と同時に、商人との取引の際にも必要となるが、同じ名前だと分かりづらいので、以下"カネ"と記述する。

- マナ獲得量

サファイア[^2]等によって増やすことが出来る値で、経験値獲得量のこと。

- マナオーブ取得量

マーキュリー[^2]等によって増やすことが出来る値で、カネ獲得量とマナオーブからの経験値獲得量のこと。

- マナ回収

魔法のリロールが可能。この際、レベルは上がらない。

### ゴールド

セル[^3]を拾うことで獲得出来る。

新たな研究を開放するのに使える。

### ライフオーブ

敵を倒した時にドロップすることがある。獲得すると体力を回復する。

### ルーン

- 狂奔のルーン

赤色のルーンを獲得することで効果を発動する。

攻撃力50%増幅、移動速度25%増加（持続時間：9秒）

- 守護のルーン

白色のルーンを獲得することで効果を発動する。

無敵状態の継続（持続時間：9秒）

- 貪欲のルーン

黄色のルーンを獲得することで効果を発動する。

アイテム獲得半径200％増加（持続時間：5秒）

- 浄化のルーン

青色のルーンを獲得することで効果を発動する。

獲得時に一部の敵を除くフィールドのすべての敵を倒す。

### AF関連

- 性軌道

[契約の箱](../artifacts/ark-of-the-covenant.md)のこと。由来は旧バージョンでの名称から。

- 箱ガチャ

終盤のウェーブ[^4]突破のために、性軌道の効果によって発動されるルーン効果を限定させるために行う操作。基本白を狙ってる。怠い。詳しいやり方はここ→[テラ](terra.md)

おもちゃの城の略称②

- リスト

- 足

- 金ルレ

- 権能

- 目

[注視者の目](../artifacts/watchers-eye.md)の略称。

- 帽子

- 赤AF

特別アーティファクトのこと。由来はAF一覧での枠の色から。

### 魔法関連

- 赤パッシブ

特別強化魔法のこと。由来は魔法一覧での枠の色から。

- テラ

[テラ電流](../magic/tera-current.md)の略称。テラ電とも。エリアの[テラ](terra.md)を指す場合もある。

- ブラ

[ブラスター](../magic/blaster.md)の略称。かつては[ブランディッシュ](../magic/brandish.md)の略称でもあった。

- ブラン

[ブランディッシュ](../magic/brandish.md)の略称。

- ブラホ

[ブラックホール](../magic/black-hole.md)の略称。

- 超

[超新星](../magic/supernova.md)の略称。

- 扉

[創造の扉](../magic/door-of-creation.md)の略称。

- 嵐

[嵐の支配者](../magic/storm-ruler.md)の略称。[冬の嵐](../magic/winter-storm.md)や[炎の嵐](../magic/firestorm.md)にも"嵐"が含まれるが、嵐といえば嵐の支配者のことを指す。

- オバマイ

[オーバーマインド](../magic/overmind.md)の略称。オバマとも。

- マキナ

[デウス・エクス・マキナ](../magic/deus-ex-machina.md)の略称。デウエク、デウマキ、デクス、DeMとも。

- ビルド

取得する融合魔法の組み合わせのこと。[^5]

- 1魔

デウス・エクス・マキナを用いたビルドのこと。

マキナが登場する前は、オーバーマインドと1つの融合魔法のみを用いて戦うビルドを指していた。

- 2融合

攻撃系の融合魔法を2つしか取らないビルドの総称。残り1枠はたいていの場合[無限動力](../magic/infinite-power.md)を取っている。

- 3融合

攻撃系の融合魔法を3つ取っているビルドの総称。

- 遅延系

[感電地帯](../magic/electric-zone.md)(EMP)や吹雪(極寒期)、霜柱、津波(極点)の総称。

- 凍結系

吹雪(極寒期)、霜柱、津波(極点)の総称。

- 素材

融合魔法を作るのに必要な魔法の内、融合したあとは発射出来ない魔法のこと。

### その他

- 赤

狂奔のルーンのこと。移動速度を上げるやつ。

- 白

無敵ルーンとも呼ぶ。守護のルーンのこと。無敵になるやつ。

- 黄

貪欲のルーンのこと。アイテムを集めるやつ。

- 青

浄化のルーンのこと。敵を殺すやつ。

- リセ

ゲームを一度閉じてから再度開き直すこと。時間をオートセーブ地点まで戻す事ができるため、様々なことをやり直せる。

- 壁

多くのプレイヤーが苦戦しているウェーブ[^6]のこと。持ち物検査とも。

難易度の高いウェーブ[^7]のことを指す場合もある。

- ウェブ外

ウェーブでない時間のこと。

- VT

ウェーブ中の、幽体化や白ルーン、力場が発動していない時間のこと。
