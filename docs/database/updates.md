# アップデート履歴

各バージョンの主な変更点と、それによる環境の変化をまとめています。

- 公式の告知は [Naver Cafe](https://m.cafe.naver.com/ca-fe/magicsurvival?tc=article) (韓国語) に出ます。このページは告知をもとに日本語で要約したもので、細かい数値は省いています。詳しくは各版の「情報源」から告知を見てください。
- 新しい版はまずベータ版で配信され、数日後に Play ストアの正式版になることがよくあります。日付は告知の日付です。
- 間違いや補足があれば、このページを編集してください。

#### 環境の変化 (所感)

長時間生存がかなり容易になった。様々な強力な要素の登場で、半永久的に走り続けられるようになったが、新たなモンスターの追加もあって序盤の難易度が上がっている。序盤さえ凌げれば魔法はなんでも好きに使える環境だと思う。

#### 環境の変化 (所感)

以前より長時間生存が厳しくなった。時間経過に伴う敵のステータス強化幅が伸びた影響が強い。
今のところチョー頑張って82がいいところ。
一方で序盤は以前より楽になった印象。以前にも増してプレイ時間を減らそうという開発者の意図が感じられる。
にも拘わらず長時間生存を目指してしまっているのは最早悪いことな気がしてきた^^;
