# 時間で変わるAF・シナジーの価値について

## ノーマルAF

- 呪文のリュック

序盤(0:00～25:00)に最も価値が高く、tierB相当の働きをする。

マナオーブを集めるのは勿論、レベル上げにも貢献するのが大きな評価点。

終盤(25:00～)以降は価値が下がり続け、40:00からはtierE相当となる。

- サファイア

序盤に最も価値が高く、tierC相当の働きをする。

レベル上げに貢献することを評価。レベル上げに貢献するAFが少ないため、[サファイア](../artifacts/sapphire.md)程度の効果量でも評価に値する。

終盤以降は価値が無いに等しいが、シナジー素材であるため、一定の価値を保つ。tierD相当。

## レアAF

- 歯車

序盤は必要が無いAF四天王の一角。AFのクールタイムを減少する意味が薄い。tierD相当。

終盤以降、じわじわと価値が上がる。57:30以降最も評価出来るAFで、tierS相当。

契約の箱、力場、世界樹の葉、肉といった強力なAFのクールタイムを減少出来るのが評価点。
